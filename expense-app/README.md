# 経費申請アプリ（画面）

ブラウザで動く、経費申請の画面です（`index.html` / `app.js` / `app.css`、ビルド不要）。
全体の説明は、リポジトリ直下の `README.md` を見てください。

## 画面

- **申請**: レシート画像 → AI読み取り → 確認 → 申請。画像は長辺1600pxに縮小して送ります。
- **一覧**: 月ごとの申請（「全期間」も選べる）。月を切り替えると、その月の分だけを取得します
  （取得済みの月は先に表示し、裏で最新に更新）。並べ替えは日付・月ごと・事業部ごと・人ごと・
  費目ごと・金額。領収書の画像は一覧に小さく出て、タップで拡大します（ドライブが作る縮小画像を
  使い、`loading="lazy"` で見える分だけ読みます）。開けない画像は 🧾 になります。
- **アカウント**（管理者のみ）: 利用者の追加・コードの再発行・無効化・事業部の割り当て、
  事業部の追加・削除。

## 作りのメモ

- 通信は Apps Script の Web アプリへの POST です。CORS のプリフライトを避けるため、
  JSON を `text/plain` で送っています（`application/json` にしないこと）。
- 起動は `bootstrap` の1往復です。前回の一覧を端末に残し（直近3か月まで）、通信の前に描きます。
- WebアプリURL・ログイン状態・一覧のキャッシュは、ブラウザの `localStorage` に保存します。
- 旧URL `/lite/` は、案内リンクを引き継いで `/` へ移動するだけのページです
  （軽量版を正式版にしたときの名残。配った案内リンクが切れないように残しています）。
